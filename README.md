# Living Town

NPC agents whose memories live in a FalkorDB graph: episodic (what happened), semantic (what they know), procedural (how they act). Gossip spreads along social edges, NPCs hand off what they know, and every player gets an isolated world graph.

Built for [Graph Hacks: Context for AI Agents](https://www.wemakedevs.org/hackathons/falkordb).
Track: **Agent Memory and Coordination**.

> Work in progress: setup, graph data model and Cypher catalogue land here as they are built.
